# 빌드·호환성 검증

이 문서는 최초 검토 브랜치의 검증 기록이다. 이후 2026-11-01 추천 변경 3편을 운영 반영했으며 최신 UI 검증은 [탐색 개선 기록](../discovery-refinement.md)을 참조한다.

검증일: **2026-10-31**. [기계 판독 결과와 정확한 CSV 변경 필드](validation.json).

## 자동 검사

`npm test` 성공: 빌드 성공, **6개 테스트 통과 / 실패 0**.

- CSV 한글 BOM, 쉼표, 인용 따옴표, 줄바꿈, 빈 마지막 셀 파싱.
- 잘못된 원본 CSV 입력 거부와 출처 보존.
- 사이트·오프라인 HTML·다운로드 CSV의 원본 데이터 일치.
- 스냅샷 SHA-256, 전 작품 재평가 포함, 추천 값 대조, 이번 변경 범위 검사.
- 식별자 변경, 누락, 보류 항목의 무근거 매체 변경 거부.
- 확정 판정의 날짜·복수 출처 누락과 보류 항목의 거짓 검증일 거부.

별도로 CSV를 파싱해 원본 178행·19열, 재평가 178행·24열, 중복 번호·제목 없음, UTF-8 BOM·CRLF 레코드 구분·일관된 열 수를 확인했다. 인용 필드 내부 URL 사이의 줄바꿈은 LF이며 CSV 파서가 필드의 일부로 보존한다. 번호·제목·원작 매체·기존 자료 기준일은 모두 그대로다. 변경된 행은 6·18·82번뿐이며 정확한 필드 차이는 JSON에 있다. `.gitattributes`는 CSV와 기준 스냅샷의 바이트를 보존한다.

## 로컬 브라우저 확인

빌드 산출물을 HTTP로 열어 Chromium / Playwright로 검사했다. 브라우저 검사 도구는 별도 작업 환경에 설치했으며 앱의 실행 의존성에 추가하지 않았다.

- 178개 빌드 데이터와 현재 원본 CSV의 완전 일치.
- 86·약사의 혼잣말은 애니, 블루 록은 만화 입문으로 표시.
- 8개 장르와 결과 수, 복합 필터, 검색·태그, 가나다 정렬, 더 보기.
- 관심 목록 저장·되돌리기·백업/병합·잘못된 파일 거부·탭 동기화.
- 기존 저장 키 `manga-shelf-favorites-v1`의 6·18·82번 별표가 추천 변경 후에도 유지.
- 재평가 CSV 실제 다운로드 바이트가 원본 파일과 일치.
- 오프라인 HTML에서도 변경된 매체와 재평가 CSV 내장 다운로드가 일치.
- 화면 폭 320·360·390·650·740·768·1024·1440px에서 가로 넘침 없음.
- 페이지 JavaScript 오류 없음. 공식 존재 증빙 필터는 66편(현재 애니 입문 권고 65편과 구별).

## 재실행

Node.js 22 이상에서 `npm test`, `npm run validate:catalog`, `npm run validate:review`를 실행한다. `npm run preview` 후 브라우저에서 위 항목을 재확인할 수 있다. 오프라인 파일은 `dist/shelf.html`이다.

`validation.json`은 이번 검증 결과의 기록이며 향후 변경에 자동으로 갱신되는 실시간 보고서가 아니다.

## 확인하지 못한 부분

이는 코드·데이터 호환성 검사다. 모든 작품의 미학적 우열, 178편 직접 감상, 원작 전체와 모든 각색의 대조, 국내외 모든 비평의 대표성, OTT 제공, 모든 외부 링크의 지속 접근성을 검증하지 않았다. 본문 접근 실패·게시일 미확인은 출처표에 남겼다. 경합 13편과 보류 148편은 추가 비교가 필요하다. 운영 사이트는 이 검토 브랜치를 합치기 전까지 기존 배포를 사용한다.
