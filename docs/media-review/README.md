# 입문 매체 재평가 조사 기록

2026-10-31 기준 기존 **178편 전부에 한국어·일본어 검색과 후보 페이지 접근을 시도**했다. 이 결과는 문헌 기반의 변경 제안이며, 178편의 본편·원작을 직접 전부 감상하거나 품질을 검증한 결과가 아니다. 비교 자료가 부족한 **148편은 보류**했다.

| 판정 | 편수 | 기존 추천 처리 |
| --- | ---: | --- |
| 변경 권고 | 3 | 검토 브랜치에서만 변경 |
| 유지 권고 | 14 | 유지(애니 원작 예외 7편 포함) |
| 경합 | 13 | 유지 |
| 보류 | 148 | 유지, 품질 검증일 비움 |

변경 제안은 **86 -에이티식스-: 소설 → 애니**, **약사의 혼잣말: 소설 → 애니**, **블루 록: 애니 → 만화**다. 같은 범위의 재구성·감정 표현 또는 경기 표현의 시즌 간 편차를 근거로 삼았고 반대 논거도 기록했다. 세 작품의 신뢰도는 모두 보통이다. 원작 매체와 기존 순위는 그대로다.

## 판단과 근거의 범위

공식 사이트·출판사 서지는 작품과 판본의 존재에 사용하고, 비교 기사·제작자 인터뷰·독자 평가는 각색 평가에 구분해서 사용했다. 제작 관계자의 인터뷰는 이해관계가 있는 자료다. 검색 후보의 일본어 제목은 검색용 가설이며 공식 원제 확정 목록이 아니다. 실사판, 다른 작품, 속편·영화의 혼동은 제외하거나 보류 사유에 적었다.

한국어 검색을 전 작품에 먼저 포함했지만, 한국어와 일본어의 독립적 비교 평가를 모두 확보한 것은 아니다. 실제 비교 근거는 일본어 문헌에 치우쳐 있다. `sources.csv`는 본문 발췌 접근 성공, 접근 실패, 검색 요약·기존 서지만 확인한 경우를 구분한다. 본문 접근 성공도 본문 전체를 정독했거나 실제 작품을 감상했다는 뜻은 아니다. 기사 게시일을 직접 확인하지 못한 경우는 `미확인`으로 남겼으며 조회일과 구분한다. 검색 요약은 본문 확인으로 표시하지 않았다. 원문 기사 전문과 내부 검색 응답은 저장소에 복제하지 않는다.

`재평가 검증일`은 제한된 범위의 **문헌 기반 판정일**이다. 보류는 비워두고 조사일만 남겼다. 경합은 비교 문헌을 확인했으나 추천 우세가 정해지지 않은 경우다. 높음 신뢰도는 사용하지 않았다. 보통은 구체적 비교가 있으나 범위·독립성·한국어 교차 확인에 제한이 있음을, 낮음은 자료가 얇거나 단일 비교·초기 방영에 치우침을 뜻한다. 애니 원작 7편은 명세의 예외 규칙으로 유지했으며 파생 매체 대비 우열을 검증한 것으로 세지 않는다.

정성 항목은 **애니가 해당 원작 범위를 각색한 경험**을 기준으로 적었다. 애니 원작 예외나 비교 자료가 없는 항목은 `판단 불가`다. 작품 전체의 점수나 매체별 총점을 뜻하지 않는다. 미공개 시즌·PV를 본편 품질의 근거로 삼지 않았고, 방영 중·후속판의 불확실성을 기록했다.

## 원본과 사이트 연결

변경 전 기준은 `625e09d5c8e71ef9e6231dce98b66bd0cb9a6168`이다. 원본 19개 열·178개 ID·작품명·원작 매체를 보존했다. 변경은 3편의 입문 매체와 86·약사의 혼잣말의 비어 있던 두 번째 공식 자료 칸·공식 확인 표시뿐이다. 기존 출처를 덮어쓰지 않았으며 기존 `자료 기준일` 2026-10-20도 일괄 갱신하지 않았다.

`애니 추천 공식 자료 확인`은 공식 존재 증빙이다. 블루 록이 만화 입문으로 바뀌어도 이전 공식 증빙을 지우지 않는다. 이 표시는 품질 판정이나 애니 부재 표시가 아니다.

사이트·오프라인 HTML·텍스트 목록의 단일 원본은 계속 `public/anime-library.csv`다. `media-review.csv`는 근거와 감사 기록이며 별도의 추천 원본이 아니다. 빌드가 두 CSV의 매체 값과 기준 작품의 식별자를 대조한다. 관심 목록의 작품 ID와 브라우저 저장 키는 유지된다. 사이트와 오프라인 파일에 재평가 CSV 다운로드 링크를 추가했다.

## 남은 검증

보류 148편의 동일 범위 비교와 경합 13편의 찬반 교차 확인이 남아 있다. 보류가 애니 부재, 원작의 우월, 기존 추천의 정확성, 미출간을 뜻하지 않는다. 특히 본문에 접근할 수 없거나 공식 소개·예고편·초기 회차만 확보한 작품은 확정 평가하지 않았다. 각 항목의 필요한 정보는 `pending.md`와 재평가 CSV에 있다. 이 PR은 전수 품질 검증 완료를 주장하지 않는다.
