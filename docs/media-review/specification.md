# Anime Library 입문 매체 추천 재평가 명세서

작성일: 2026-10-31  
대상 데이터: [`public/anime-library.csv`](https://raw.githubusercontent.com/nu4ddi4/Anime-Library/refs/heads/main/public/anime-library.csv)  
작업 대상: 기존 작품 전체(원본 확인 당시 178개). **이 문서의 예시는 확정 수정 지시가 아니라 우선 검증할 가설**이다.

## 1. 목표와 비목표

- 목표: 각 작품을 **처음 접할 때 가장 좋은 경험을 제공하는 매체(애니/만화/소설)**를 작품별 근거로 선정한다.
- 감상 매체는 *분량이 가장 많거나 원작이라는 이유*가 아니라 **표현력, 완성도, 핵심 서사의 보존**으로 판단한다.
- 애니메이션이 있으면 애니를 **먼저 평가**하되, **자동으로 애니를 선택하지 않는다**. 판정이 접전이면 명시적으로 `경합` 처리한다.
- 비목표: 작품의 재미 자체나 순위(기존 `추천 순서`) 재정렬, 원작 매체 변경, OTT 시청 가능 여부 추정, 작품 전체를 아직 각색하지 않은 애니를 완결작으로 간주하기.

## 2. 핵심 판단 원칙

### 2.1 애니 우선 조건

1. 애니화한 범위의 사건·인물 관계·주요 복선·감정선이 원작과 실질적으로 일치한다.
2. 움직임, 액션, 음악, 성우, 촬영·편집, 색채, 배경 등이 경험을 의미 있게 향상한다.
3. 원작과 비슷하거나 더 좋은 시각적 완성도를 보이거나, 그림 스타일이 달라도 이를 보완할 만한 연출적 성취가 있다.
4. 재구성·각색이 이야기의 명료함, 리듬, 몰입도를 높이며 핵심 의미를 훼손하지 않는다.
5. 유명하다는 사실, 제작사 명성, PV 품질만으로 결정하지 않는다. 방영한 실제 본편을 평가한다.

### 2.2 만화 우선 조건

1. 애니에서 빠진 장면·내면·관계 변화·복선이 작품 이해나 감정적 설득력에 중요한 영향을 미친다.
2. 원작의 컷 분할, 구도, 여백, 페이지 넘김, 시선 유도, 표정 및 정지 이미지의 강도가 영상화에서 줄어들었다.
3. 애니의 작화 안정성·움직임·편집이 원작의 주요 강점을 재현하지 못한다.
4. 시즌 간 품질·각색 차이가 커서 처음부터 끝까지 일관된 경험이 필요하다.
5. 단순한 '원작 분량이 많음'만으로 만화를 우선하지 않는다. 애니가 좋은 입문편이고 만화가 후속 내용에 적합할 수도 있다.

### 2.3 소설 우선 조건

1. **인물의 심리, 독백, 서술 트릭, 세계관의 작동 원리, 복선**이 작품의 중심인데 다른 매체에서 의미 있게 손실된다.
2. 애니/만화가 서사를 과도하게 축약하거나 인물 해석을 바꿔 핵심 동기와 갈등 이해를 어렵게 한다.
3. 문체·시점·정보 공개 순서 자체가 핵심 예술적 경험인 경우.
4. 단, **소설이 더 상세하다는 이유만으로 소설 우선 판정 금지**. 영상·만화의 뛰어난 표현력과 입문 난이도 이점을 함께 따진다.
5. 소설과 만화 중 어떤 각색을 비교하는지도 식별한다. 동명의 만화판이 여럿인 경우 판본·작가를 분리한다.

## 3. 판단 절차: 매체별 순서와 우선순위

1. **동일 작품 확인**: 작품명·다른 이름·원작 매체·각색 판본 식별. 극장판, TVA, 리메이크, 시즌, OVA, 특별편 구분.
2. **실제 공개 여부 및 커버 범위 확인**: 공개 전·예고편만 존재·방영 중·완결·부분 각색 여부를 확인한다. 미공개 작품은 영상의 품질을 평가하지 않는다.
3. **공정한 범위 비교**: 애니 1기와 만화 완결 전체를 단순 비교하지 말고, **애니가 각색한 동일 범위**를 1차 평가한다. 별도로 이야기 전체를 감상할 때의 연속성을 평가한다.
4. **결격 사유 우선 판별**: 핵심 인물·사건·복선 삭제, 지속적인 작화 붕괴, 중요한 각색 오류, 후반부 미완성·큰 품질 저하가 있는지 확인한다. 중대한 결격이 검증되면 영상의 장점만으로 덮지 않는다.
5. **표현 비교**: 시각적 표현·움직임·음악/연기·컷/문장/시점·감정선·서사 밀도·각색 완성도 비교.
6. **수용자 평가 교차검증**: 가능하면 한국어 평가(국내 커뮤니티, 리뷰, 평론)를 우선하고 일본어 자료로 보완한다. 영어권 반응은 추가 참고 자료다. 서로 다른 근거를 복수 수집한다.
7. **최종 판정**: `애니`, `만화`, `소설`, `경합`, `보류` 중 하나. 기존 CSV `입문 추천 매체`는 `애니/만화/소설` 체계를 유지할 수 있으므로, **경합·보류는 별도 `재평가 상태` 열에서 표현**하고 이때 추천 매체를 임의 변경하지 않는다.
8. **검증 기록**: 기존 값, 검토 대상 판본/시즌, 변경 여부, 사유, 출처, 평가일 작성.

### 예외와 우선 규칙

- **애니 자체가 원작**: 소설화·만화화가 나중에 나왔다는 이유로 원작 매체를 바꾸지 않는다. 특수한 사정이 없으면 애니 우선.
- **애니 공개 전**: 신뢰성 있는 본편 평가가 없으면 새 애니 추천을 확정하지 않는다.
- **방영 중**: 본편 공개 분량에 대한 잠정 평가만 가능. 후반 작화·완결 방식은 유보.
- **복수 시즌**: 시즌별 수준과 핵심 생략을 함께 기록한다. `1기 애니 → 이후 만화` 등의 혼합 감상 경로는 보조 권고로 제시할 수 있지만, 기본 입문 매체는 한 개로 선택하거나 경합 처리.
- **예산·접근성·스포일러**: 비싼 소장 비용, OTT 독점 여부 등은 작품의 미학적 우열과 구분하여 별도 메모로 처리.
- **호불호**: 개인의 취향과 평균적 평가를 혼동하지 않으며, 평가가 심하게 갈리면 신뢰도를 낮춘다.

## 4. 정성 평가 루브릭

각 요소를 `우수/양호/비슷/열세/판단 불가`로 기술하고 **총점 하나로 기계적으로 결정하지 않는다**.

| 요소 | 애니의 장점 확인 | 만화/소설의 반대 근거 |
|---|---|---|
| 서사 충실도 | 핵심 사건·동기·복선 유지 | 삭제·압축·재배열로 의미 변경 |
| 감정 전달 | 연기, 표정, 음향, 영상 리듬 | 섬세한 내면, 독백, 여백, 문장 |
| 연출 | 액션 동선, 촬영, 음악, 편집 | 컷 분할, 페이지 연출, 시점·서술 트릭 |
| 그림·영상 | 작화 안정성, 디자인, 배경 | 원작의 구도, 선화, 밀도, 고유한 미술 |
| 전체 경험 | 완성도와 일관성, 적절한 끝맺음 | 누락 분량, 시즌 간 차이, 미완결 |

**판정 정책**
- `변경 권고`: 새 매체의 구체적 우세와 기존 매체 대비 핵심 손실이 적다는 근거가 확인됨.
- `유지 권고`: 기존 매체의 강점이나 타 매체의 중요한 약점이 확인됨.
- `경합`: 서로 다른 핵심 장점이 비슷하거나 자료 간 평가가 충돌함. `입문 추천 매체` 기존 값 유지.
- `보류`: 미방영/초기 방영/출처 부족/판본 혼동. `입문 추천 매체` 기존 값 유지.

**신뢰도**: `높음`(공식 판본 확인 + 실제 본편·원작 비교 근거 + 독립적 이용자/비평 근거 복수), `보통`(신뢰할 만한 근거는 있으나 비교의 제한 존재), `낮음`(인상 위주, 단일 출처, 방영 초기). 출처 개수만으로 높음 판정하지 않는다.

## 6. 근거 조사 기준

1. **사실 확인**: 작품·시즌·방영 상태·원작/각색 판본은 애니 공식 사이트, 출판사, 제작사, 서지 등 1차 자료 우선.
2. **품질·수용자 평가**: 국내 이용자 리뷰·커뮤니티 및 국내 평론을 먼저 확인, 일본 반응으로 교차검증. 영어권은 보조. 게시물 작성일과 애니 시즌·회차를 확인.
3. **상반된 시각을 함께 기록**: 애니가 좋다는 반응뿐 아니라 만화/소설이 우수하다는 가장 설득력 있는 반대 근거를 확인한다.
4. **원작 내용 누락 여부**: 가능하면 공식 원작과 본편을 비교한 구체적 근거를 활용. 팬덤의 잘못된 추측이나 작품 혼동 주의.
5. **숫자 평점의 한계**: 플랫폼별 유저층·표본·방영 시점이 다름. 평점만으로 판정 금지.
6. **출처가 부족하면 정직하게 `보류`**. 출처 링크·확인일 없이 품질을 검증했다고 표기하지 않는다.
7. 추천 대상이 2026-10-31 이후 발표·방영된 경우 실제 실행일 기준 최신 정보로 업데이트하되, 미래 시즌이 기존 시즌의 결함을 소급해 해결한다고 가정하지 않는다.

## 7. 데이터 변경 설계

### 원본 컬럼을 보존할 것

원본 CSV 헤더에는 `추천 순서, 작품명, 원작 매체, 입문 추천 매체, 장르, 태그, 다른 이름, 자료 확인 상태, 매체 대조, 애니 추천 공식 자료 확인, 메모, 자료 기준일, 자료 1 이름, 자료 1 URL, 자료 1 확인 범위, 자료 2 이름, 자료 2 URL, 자료 2 확인 범위, 세부 장르(원본)` 등이 있다.

- `추천 순서`: 작품 순위의 의미. **변경 금지**.
- `원작 매체`: 창작·출판 분류. **추천 결과에 맞추려고 변경 금지**.
- `입문 추천 매체`: 검증 완료한 행에서만 `애니/만화/소설` 중 하나로 수정.
- `애니 추천 공식 자료 확인`: 이전 데이터에서 `해당 없음`은 **애니가 없음을 의미하지 않을 수 있음**. 추천 상태와 공식 존재 증빙을 혼동하지 않는다. 애니 존재 확인 후 적절히 별도 갱신.
- `자료 기준일`: 검증하지 않은 자료를 새 날짜로 일괄 갱신하지 않는다.

### 추가 권장 컬럼

| 컬럼 | 허용 값/내용 |
|---|---|
| `기존 입문 추천 매체` | 재평가 시작 시 값(감사 추적용; 가능하면 별도 변경 이력으로 관리) |
| `재평가 상태` | `변경 권고` / `유지 권고` / `경합` / `보류` |
| `추천 신뢰도` | `높음` / `보통` / `낮음` |
| `추천 근거` | 1~3문장, 감상 경험의 비교 우위 명시 |
| `각색 평가` | 범위·누락·변경·시즌별 품질 관련 핵심 정보 |
| `비교 대상` | 예: `TVA 1~2기 vs 만화 동일 분량` |
| `재평가 검증일` | `YYYY-MM-DD`, 실제 검증한 날 |
| `재평가 출처` | 검증 가능한 링크 2개 이상 권장; 출처 유형/시점 명시 |
| `권장 감상 경로` | 선택 사항: `애니 1기 → 만화 n권부터` 등 정확한 대응 확인 시에만 |

웹 UI가 이 컬럼들을 모두 표시할 필요는 없다. CSV 구조 변경이 기존 렌더링을 깨지 않는지 코드 확인 후 반영한다. 가능하면 **원본 CSV를 보존하고 별도 `media-review.csv`에 행별 근거를 관리**하여 기존 스키마와 호환성을 유지한다.

## 8. 에이전트 실행 순서와 검수

1. 저장소를 확인하고 현재 브랜치·CSV 백업 확보. 변경 전 행 수·헤더·중복 작품·빈 값 검사.
2. 전체 작품에 대해 애니메이션 존재/판본/커버 범위 확인. 공식 존재 확인 여부와 추천 판정은 별도로 관리.
3. 변경 가능성이 큰 작품부터 원작과 애니의 동등 분량 비교 및 한국·일본 리뷰 수집.
4. 작품별 `유지/변경/경합/보류`를 결정. 결정 근거가 부족하면 현 값 유지.
5. CSV와 근거표를 작성하되, 178행 및 `추천 순서`·`원작 매체` 무손실 보존.
6. UTF-8 BOM, 쉼표·따옴표·줄바꿈 이스케이프, 줄 수/열 수 검사. 한국어 문자 깨짐 확인.
7. 앱에서 CSV를 읽는 로직·필터/정렬/배포 경로를 점검하고 빌드·테스트.
8. 변경 작품은 `기존 → 신규 / 이유 / 반론 / 출처 / 검증일` 표로 정리. **근거 없는 추천 변경은 허용하지 않는다**.
9. 사용자 검토 전에는 가능하면 별도 브랜치·PR로 제시. 출처 부족·접근 불가 항목은 성공한 것처럼 기재하지 않는다.

### 최종 산출물

- (A) 전체 178개 작품 재평가표(추천 변경 여부 포함)
- (B) 변경 권고 목록 및 반대 논거, 검증 가능한 URL
- (C) 보류·경합 목록과 판단을 막는 부족한 정보
- (D) 호환성 유지된 CSV 또는 별도 리뷰 데이터, 변경 diff
- (E) 빌드·검증 결과와 확인하지 못한 부분

## 9. 품질 체크리스트

- [ ] 모든 작품을 검토하고, 기존 추천을 무조건 유지하지도 무조건 애니로 바꾸지도 않았다.
- [ ] 애니가 있는 작품은 우선 검토했지만, 미방영·방영 중인 작품을 완결작으로 평가하지 않았다.
- [ ] 소설의 분량·만화의 원작 여부만으로 결론 내리지 않았다.
- [ ] 감정선·컷 연출·각색 생략·시각/청각 연출의 손익을 구체적으로 비교했다.
- [ ] 국내 평가와 일본 평가, 찬반 근거를 함께 살폈다.
- [ ] 결정마다 검증 가능한 출처·날짜·판본이 있다.
- [ ] 모든 작품 번호·작품명·원작 매체가 원본과 일치한다.
- [ ] `경합`·`보류`는 기존 추천을 함부로 수정하지 않았다.
- [ ] 기존 사이트가 업데이트된 데이터로 정상 동작한다.
