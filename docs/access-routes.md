# 구매·시청 경로와 펼침 UI

2026-11-01 조사. 사이트의 작품명을 펼치면 **책으로 읽기 / 영상으로 보기**에서 바로 이동한다. 전체 목록은 178편이며, 경로는 기존과 같은 `public/anime-library.csv`에서 관리한다. 구매 경로 기능은 추천 매체 재평가와 독립적이다. 이후 추천 다듬기 요청으로 반영한 3편의 변경은 [입문 재평가 기록](media-review/README.md)에 있다.

| OTT 공식 작품 페이지 | 135편 |

## 확인한 것과 확인하지 않은 것

서점 링크는 기존 CSV에 있던 리디·YES24·교보문고 등의 국내 본편 서지를 재사용했다. 기존 기준일 **2026-10-20**을 유지했으며 현재 재고·판매 버튼·전자책 또는 종이책 구매 가능 여부를 새로 확인한 것으로 표시하지 않는다. 상품의 권수·형식은 링크에서 확인한다.

178개 작품명을 국내 OTT 공식 도메인에서 검색하고, 동명 작품·외전·실사·시즌 혼동을 확인했다. 후보 중 138편의 페이지에 본문 접근을 시도했으며, 서비스 종료가 표시된 문학소녀·바카노·너는 달밤에 빛나고는 제외했다. 해파리 공주의 실사 드라마는 2010년 애니 페이지로 교체했고, 데스노트 실사 영화·몬스터 동명 영화·20세기 소년 관련 예능 등은 애니 경로에 넣지 않았다. 지구의 운동에 대하여의 정식 넷플릭스 페이지는 추가로 본문 확인했다.

OTT는 **2026-11-01 확인한 공식 작품 안내 페이지**다. 비로그인으로 확인했으므로 국내 계정의 실제 재생 권한·요금제·대여/구매·제공 종료일·전체 회차를 검증한 목록은 아니다. 지역 제한 문구가 나오는 공식 카탈로그 페이지도 있어 현재 제공을 확정하지 않는다. 페이지가 존재한다는 것과 지금 볼 수 있다는 것을 구분하기 위해 `시청 가능` 배지를 사용하지 않는다.

우선 확인된 경로 한 개를 등록했다. 모든 서비스의 독점·입점 현황을 전수 조사한 표가 아니다. 후속 시즌이나 극장 총집편만 확인된 경우 **해당 판본 이름**을 적었다. 예를 들어 봇치 더 록은 극장 총집편 전편이며 TVA 경로로 오인하지 않도록 표시한다. 나는 내일, 어제의 너와 만난다·오늘 밤 세계에서 이 사랑이 사라진다 해도는 **실사 영화**로 구분한다. 이것은 입문 추천 매체를 바꾼다는 뜻이 아니다.

리디·YES24·라프텔·JustWatch 검색 링크는 작품명을 URL 인코딩해 만든 탐색 경로다. 제공·판매를 확인한 링크와 구분한다. 없는 직접 링크가 미출간이나 애니 부재를 뜻하지 않는다. 작품 특정이 안 된 151번은 직접 상품 링크를 만들지 않고 확인 필요 안내를 표시한다.

## CSV 편집

기존 19개 열을 보존하고 10개 선택 열을 추가했다. 각 `서점 1`·`OTT 1` 묶음은 `이름, URL, 판본, 확인 방식, 확인일`로 구성된다. 더 필요하면 같은 방식으로 번호를 늘린 열 묶음을 추가한다.

- 확인 방식: `기존 서지` / `공식 페이지·본문` / `공식 페이지·검색`.
- 날짜는 경로 자체의 확인일이며 기존 `자료 기준일`과 독립적이다.
- 빈 묶음은 링크 미등록이다. 일부 칸만 채우거나 HTTPS가 아닌 URL·잘못된 날짜를 넣으면 빌드가 실패한다.
- 웹·오프라인 HTML·다운로드 CSV는 모두 같은 원본을 사용한다. 원본 데이터 178개의 번호·제목·원작·추천·기존 출처·날짜를 유지했다.

## 잘림과 애니메이션

데스크톱 사이드바에 화면 높이에 맞는 최대 높이와 세로 스크롤을 설정했다. 화면 높이가 작거나 다운로드 영역을 펼쳐도 끝의 링크까지 접근할 수 있다. 모바일에서는 문서 흐름을 따라 배치하며 기존 하단 탐색을 유지한다.

다운로드·필터·자료 내역의 네이티브 `details/summary`와 작품 상세에 약 230ms의 높이 전환을 넣었다. 닫힘·열림 도중 다시 누르면 현재 높이에서 다음 상태로 전환한다. 동작 줄이기 설정과 애니메이션 미지원 환경은 즉시 전환한다. 닫는 작품 상세의 링크는 즉시 키보드 탐색에서 빠지고, 전환 후 패널을 숨긴다.

## 검증

빌드·자동 검사와 로컬 Chromium에서의 작은 화면·연속 토글·키보드·동작 줄이기·다운로드·오프라인 확인 결과는 [검증 기록](access-validation.json)에 기록한다. 이 검사는 외부 서비스에서 실제 구매하거나 영상을 재생하는 검사가 아니다.
