# 조건·추천·표지 개선

2026-11-01. 동기화는 이후 작업으로 남겼다.

## 조건

구매·시청 경로 필터에서 서점/OTT 종류 또는 리디·YES24·교보문고·티빙·넷플릭스·디즈니+·왓챠의 등록된 작품 페이지를 기준으로 좁힐 수 있다. 서비스 목록은 현재 CSV에서 생성한다. 실제 구매·시청 가능 여부를 보증하는 필터가 아니다.

여러 검색어는 각각 제목·별칭·장르·태그·원작/입문 매체·서비스 중 하나에 일치해야 한다. 예를 들어 `판타지 소설`, `장송 프리렌`처럼 입력할 수 있다. 장르·서비스·원작·입문 매체 필터는 함께 적용한다. 자료 필터에는 문헌 검토 기록이 있는 30편을 따로 찾는 조건을 추가했다.

## 추천

기존 문헌 조사에 따른 **86 / 약사의 혼잣말: 소설 → 애니**, **블루 록: 애니 → 만화**를 반영했다. 순위·작품 ID·제목·원작 매체는 보존했다. 3편 모두 신뢰도 보통이며, 직접 본편·원작을 전부 감상한 판정은 아니다. [기존 조사·반론·제한](media-review/README.md)을 계속 제공한다.

상세 화면에는 변경 3편·유지 14편·경합 13편의 이유, 비교 대상, 반대 근거, 자료 접근 한계를 표시한다. 보류 148편에는 잠정 제안임을 밝힌다. 애니 원작 7편의 유지는 명세의 예외 규칙에 의한 것이며 파생 매체 대비 우열을 검증했다는 뜻이 아니다.

`한 편 골라보기`는 현재 검색·필터·목록에 맞는 후보에서 무작위로 고른다. 전체 목록에서는 관심 작품을 제외한 후보를 우선하고, 없으면 관심 작품을 포함해 고른다. 여러 후보가 있을 때 직전 선택의 반복을 피한다. 작품 특정이 안 된 항목은 선택하지 않는다. 조건이 바뀌면 기존 카드를 닫으며, 선택 작품이 다음 페이지에 있어도 안내 버튼으로 해당 상세를 열 수 있다. AI 개인화 추천이나 새 매체 평가를 실행하는 기능은 아니다.

## 표지

기존 국내 서점 URL을 기반으로 공개 페이지의 제목·표지 주소·실제 `srcset`을 확인했다. **제목과 서점 판본 ID가 일치한 39편**만 등록했다. 전 작품의 표지를 확보하지 않았다. 일부 시리즈·합본 페이지는 엄격한 판본 식별 조건을 충족하지 못했고, 수집 도중 요청 제한 응답이 발생해 반복 요청하지 않았다. 확인하지 않은 이미지 주소를 추측해 채우지 않았다.

등록한 것은 리디가 제공한 폭 120px 이미지 주소다. 이미지를 생성·편집하거나 기사·본문을 저장소에 복제하지 않았다. CSV에 이미지 주소·출처·확인일을 기록하고 작품 상세에 서점 판본의 표지임을 표시한다. 외부 CDN 이미지는 지연 로딩하며, 크기를 예약하고 실패하면 기본 표시로 대체한다. 오프라인 HTML은 외부 이미지를 요청하지 않는다.

## 검증

`npm test` 8개 통과. [브라우저 검증 기록](discovery-validation.json)에 서비스·장르 복합 조건, 여러 검색어, 추천 후보·반복·관심 작품 처리, 페이지 밖 작품 열기, 3편의 추천 값과 반론, 작은 화면, 접근성, 이미지 실패 처리, 오프라인 요청 검사를 기록한다. 외부 표지의 실제 CDN 로딩은 배포 미리보기에서 별도로 확인한다.

전체 작품·추천 매체의 편집 원본은 `public/anime-library.csv`다. `media-review.csv`는 문헌 비교 근거이며 빌드에서 매체 값의 일치를 검증한다. 화면의 30개 입문 안내는 이 조사표에서 생성하므로 HTML에 이유를 수동 복사하지 않는다.
