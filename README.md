# 감상 서가

178편의 만화·소설·애니를 8개 장르에서 찾아보고 관심 작품을 모으는 개인 서가입니다.

- 사이트: https://ani.feentn.com
- 검색: 작품명, 별칭, 장르, 세부 태그 (공백·문장부호 무시)
- 원작·추천 매체·장르·자료 확인 필터, 추천순·가나다순 정렬
- 관심 목록 브라우저 저장, JSON 백업 및 병합 불러오기
- 모바일 접이식 필터, 키보드 조작, 단독 HTML 다운로드

## 실행

Node.js 22 이상과 Python 3을 사용합니다. 외부 런타임 의존성은 없습니다.

```sh
npm run build
npm run preview
```

http://localhost:4174 에서 확인합니다. `dist/shelf.html`은 CSS, JavaScript, 목록을 포함한 독립 실행 파일입니다.

## Cloudflare Pages

GitHub 저장소 `nu4ddi4/Anime-Library`의 `main` 브랜치를 연결합니다.

| 설정 | 값 |
| --- | --- |
| 빌드 명령 | `npm run build` |
| 출력 디렉터리 | `dist` |
| Node.js | 22 (`.node-version`) |
| 사용자 지정 도메인 | `ani.feentn.com` |

`main`에 푸시하면 Pages에서 자동 배포합니다. 사용자 지정 도메인을 Pages에 등록하고, 해당 Pages 프로젝트의 `*.pages.dev` 주소를 가리키는 CNAME 레코드를 사용합니다.

## 데이터와 저장

첨부된 `감상서가_8장르_적용.html`의 178편, 장르, 자료 링크와 수정 내역을 보존했습니다. 자료 기준일은 원본의 **2026년 10월 20일**이며 최신 제공·판매 현황을 실시간 조회하지 않습니다.

관심 목록은 현재 브라우저와 주소에 저장됩니다. 기기나 도메인이 달라지면 자동으로 옮겨지지 않으므로 **관심 목록 백업 → 백업 불러오기**를 사용합니다. 불러오기는 기존 목록과 합치며, 다른 작품 ID나 잘못된 형식은 거부합니다. 서버·계정 동기화는 없습니다.

`index.html`에는 원본 데이터와 마크업, `styles.css`에는 화면 스타일, `app.js`에는 브라우저 기능이 있습니다. `public/catalog.md`는 원본에 포함된 정리 목록입니다.
