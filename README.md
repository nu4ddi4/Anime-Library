# 감상 서가

178편의 만화·소설·애니를 8개 장르에서 찾아보고 관심 작품을 모으는 개인 서가입니다.

- 사이트: https://ani.feentn.com
- 검색: 작품명, 별칭, 장르, 세부 태그 (공백·문장부호 무시)
- 원작·추천 매체·장르·자료 확인 필터, 추천순·가나다순 정렬
- 관심 목록 브라우저 저장, JSON 백업 및 병합 불러오기
- 모바일 하단 탐색, 접이식 필터, 적용 조건 개별 해제
- 제목에서 작품 정보·근거 자료 펼치기, 관심 변경 되돌리기
- 24편씩 더 보기, 장르별 결과 수, `/` 검색·`Escape` 지우기
- 단독 HTML 다운로드 (오프라인 검색과 탐색 포함)

## 전체 목록 다운로드·수정

- **[CSV 다운로드](https://github.com/nu4ddi4/Anime-Library/raw/refs/heads/main/public/anime-library.csv)** · [GitHub에서 표로 보기](public/anime-library.csv)
- **[사이트에서 CSV 받기](https://ani.feentn.com/anime-library.csv)**

엑셀에서는 파일을 열고, 구글 시트에서는 **파일 → 가져오기 → 업로드**로 CSV를 선택하세요. 한글 호환을 위해 UTF-8 BOM을 포함합니다. 여러 장르·태그·별칭은 ` / `로 구분하며, 근거 자료마다 이름·URL·확인 범위를 별도 열에 담습니다. `애니 추천 공식 자료 확인`의 `해당 없음`은 애니가 없다는 뜻이 아니라 해당 확인 대상이 아니라는 뜻입니다.

**목록의 단일 원본은 `public/anime-library.csv`입니다.** CSV를 수정하고 `main`에 반영하면 Pages 빌드가 이를 읽어 사이트·오프라인 HTML·텍스트 목록을 함께 갱신합니다. HTML에 수동으로 데이터를 복사할 필요가 없습니다. 브라우저에서는 빌드 시 생성한 데이터를 읽으므로 오프라인 HTML도 같은 목록으로 동작합니다.

- `추천 순서`는 기존 관심 목록이 작품을 식별하는 번호이기도 합니다. 기존 번호를 재배정하거나 다른 작품에 재사용하지 말고, 새 작품에는 고유한 양의 정수를 부여하세요.
- 날짜는 `YYYY-MM-DD`, 매체는 `만화`·`소설`·`애니`·`미확인`을 사용합니다. 장르는 사이트의 8개 장르 중에서 선택합니다.
- 제목, 메모 등에 쉼표·따옴표·줄바꿈이 있으면 엑셀·시트의 CSV 내보내기를 사용해 필드를 올바르게 인용하세요.
- `npm run validate:catalog`로 중복 번호·누락 열·장르·날짜·자료 링크를 확인합니다. 잘못된 CSV는 빌드가 실패하며 기존 운영 배포가 유지됩니다.
- `세부 장르(원본)` 열은 첨부 파일의 예전 분류를 보존합니다. 사이트의 장르 필터는 `장르` 열을 사용합니다.

## 실행

Node.js 22 이상과 Python 3을 사용합니다. 외부 런타임 의존성은 없습니다.

```sh
npm run build
npm run preview
```

http://localhost:4174 에서 확인합니다. `dist/shelf.html`은 CSS, JavaScript, 목록을 포함한 독립 실행 파일입니다.

## Cloudflare Pages

GitHub 저장소 `nu4ddi4/Anime-Library`의 `main` 브랜치를 연결합니다.

| 설정 | 값 |
| --- | --- |
| 빌드 명령 | `npm run build` |
| 출력 디렉터리 | `dist` |
| Node.js | 22 (`.node-version`) |
| 사용자 지정 도메인 | `ani.feentn.com` |

`main`에 푸시하면 Pages에서 자동 배포합니다. 사용자 지정 도메인을 Pages에 등록하고, 해당 Pages 프로젝트의 `*.pages.dev` 주소를 가리키는 CNAME 레코드를 사용합니다.

## 데이터와 저장

첨부된 `감상서가_8장르_적용.html`의 178편, 장르, 자료 링크와 수정 내역을 보존했습니다. 자료 기준일은 원본의 **2026년 10월 20일**이며 최신 제공·판매 현황을 실시간 조회하지 않습니다.

관심 목록은 현재 브라우저와 주소에 저장됩니다. 기기나 도메인이 달라지면 자동으로 옮겨지지 않으므로 **관심 목록 백업 → 백업 불러오기**를 사용합니다. 불러오기는 기존 목록과 합치며, 다른 작품 ID나 잘못된 형식은 거부합니다. 서버·계정 동기화는 없습니다.

`public/anime-library.csv`에는 전체 작품 원본, `index.html`에는 화면 틀과 과거 수정 내역, `styles.css`에는 스타일, `app.js`에는 브라우저 기능이 있습니다. `scripts/catalog.mjs`가 CSV를 읽고 검사하며 `npm run build`가 배포용 데이터와 텍스트 목록을 생성합니다.
